# CareerBridge

### Ultimate Internship Management System

CareerBridge is a web-based internship management platform designed to connect students and employers through a centralized internship and recruitment workflow.

## Project Overview

The project aims to simplify internship management by supporting the discovery of opportunities, application tracking, candidate review, and internship-related follow-up.

## Core Features

### Student
- Browse internship and job opportunities.
- View opportunity details.
- Submit applications and track their status.

### Employer
- Maintain employer or company information.
- Publish and manage opportunities.
- Review applications and shortlist candidates.
- Manage interview and selection information, where implemented.

### Administrator
- Manage user accounts and platform-level information.
- Oversee announcements, notifications, and reports where implemented.

## Intended Workflow

1. Employers publish internship opportunities.
2. Students browse opportunities and submit applications.
3. Employers review applications and update candidate statuses.
4. Interview, selection, and internship follow-up information is managed where supported by the implementation.
5. The administrator oversees platform-level management.

## Local Setup

If the project uses PHP, MySQL, and XAMPP:

1. Install and open XAMPP.
2. Start Apache and MySQL.
3. Place the project folder in XAMPP's `htdocs` directory.
4. Open phpMyAdmin at `http://localhost/phpmyadmin/`.
5. Create the database required by the project configuration and import the provided SQL file, if available.
6. Update the database connection settings to match your local environment.
7. Open the project at `http://localhost/CareerBridge/` if the folder is named `CareerBridge`.

These setup steps are conditional; use the actual database name, credentials, SQL file, and entry point supplied with the project.
